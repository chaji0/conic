# 실시간 멀티플레이어 + 도감 자동 전송 설정 방법

이 게임(index.html)은 파일 하나로 동작하는 정적 페이지라서, 그 자체로는 "다른 학생이 실시간으로 보이는 기능"이나 "구글시트에 자동으로 기록을 쌓는 기능"을 만들 수 없습니다. 대신 무료로 쓸 수 있는 두 개의 구글/파이어베이스 서비스에 연결하도록 코드를 준비해뒀습니다. 아래 두 가지를 설정하면 바로 동작하고, 설정하지 않아도 게임 자체는 지금처럼 혼자 플레이하는 모드로 정상 동작합니다.

## 1. 실시간 멀티플레이어 (Firebase Realtime Database)

1. https://console.firebase.google.com 에서 새 프로젝트를 만듭니다 (무료 Spark 요금제로 충분합니다).
2. 왼쪽 메뉴에서 "빌드 -> Realtime Database" -> "데이터베이스 만들기"를 클릭합니다. 보안 규칙은 아래처럼 설정하세요. 학생들이 로그인 없이 접속해도 동작하면서, 낯선 사람이 데이터베이스를 통째로 읽거나 지우는 것은 막아줍니다:
   ```json
   {
     "rules": {
       "rooms": {
         "$room": {
           "players": {
             ".read": true,
             "$player": {
               ".write": true,
               ".validate": "newData.hasChildren(['name','x','z'])"
             }
           }
         }
       }
     }
   }
   ```
   수업이 끝나면 `.read` / `.write` 를 `false` 로 바꿔 잠가두는 걸 권장합니다.
3. 프로젝트 설정(톱니바퀴) -> "내 앱"에서 "웹 앱 추가"(</> 아이콘)를 클릭하고, 나오는 `firebaseConfig` 객체를 복사합니다.
4. `index.html` 파일을 텍스트 편집기로 열고 `FIREBASE_CONFIG` 를 검색합니다(파일 맨 위쪽, "0. 기본 설정" 구역에 있습니다). 아래처럼 값을 채워 넣고 저장합니다:
   ```js
   var FIREBASE_CONFIG = {
     apiKey: "복사한 값",
     databaseURL: "복사한 값",
     projectId: "복사한 값"
   };
   ```
5. 저장한 파일을 학생들에게 나눠주면(또는 웹에 올리면), 같은 파일을 연 학생들끼리 서로의 위치가 실시간으로 보입니다.
   - 반을 여러 개로 나누고 싶다면, 학생들에게 링크 끝에 `?room=1반` 처럼 붙여서 열게 하면 방이 분리됩니다. (기본값은 `daechi-classroom`)

## 2. 도감 자동 구글시트 기록 (Google Apps Script)

같은 폴더에 있는 `apps-script-template.gs` 파일을 열어 안내를 따라 그대로 진행하면 됩니다. 요약하면:

1. 새 구글 스프레드시트를 만듭니다.
2. 확장 프로그램 -> Apps Script 를 열고, `apps-script-template.gs` 내용을 전부 붙여넣습니다.
3. 배포 -> 새 배포 -> 웹 앱, 액세스 권한 "모든 사용자"로 배포하고 나오는 URL을 복사합니다.
4. `index.html`에서 `SHEETS_WEBHOOK_URL` 을 검색해 그 URL을 붙여넣고 저장합니다.

이제 학생이 게임에서 "🚪 나가기" 버튼을 누르고 "도감을 전송하시겠습니까?"에서 "네"를 누르면, 그 학생의 이름/시간/점수/발견한 이차곡선 목록이 스프레드시트에 자동으로 한 줄씩 추가됩니다.

`SHEETS_WEBHOOK_URL`을 아직 설정하지 않았다면, "네"를 눌렀을 때 대신 그 학생 기기에 CSV 파일이 바로 다운로드됩니다 (엑셀에서 바로 열립니다). 이 파일들을 나중에 선생님이 모아서 취합할 수 있습니다.

## 두 가지 다 설정하지 않아도 되나요?

네. 둘 다 선택 사항입니다. 아무것도 설정하지 않으면 게임은 지금까지처럼 혼자 플레이하는 모드로 동작하고, 나가기를 누르면 그 학생 기기에 CSV가 다운로드됩니다. 나중에 준비되면 그때 두 값만 채워 넣으면 됩니다.
