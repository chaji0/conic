# 실시간 동시접속 설정 방법 (Firebase Realtime Database)

같은 방에 들어온 친구들이 지도 위에 고양이로 함께 보이는 기능입니다. 설정값은 `src/multiplayer.js` 의
`FIREBASE_CONFIG` 에 들어 있고, `null` 로 두면 외부 네트워크 요청 없이 혼자 플레이합니다.

> ⚠️ 현재 선생님의 Firebase 프로젝트(`geometry-c494f`) 값이 이미 채워져 있습니다. 파일을 새로 만들거나
> 옮기는 과정에서 이 값을 `null` 로 되돌리거나 지우면 동시접속이 통째로 꺼집니다. 수정 후에는
> `grep projectId src/multiplayer.js index.html` 로 값이 살아 있는지 확인하세요.

## 다른 Firebase 프로젝트로 바꾸려면

1. https://console.firebase.google.com 에서 프로젝트를 만듭니다 (무료 Spark 요금제로 충분합니다).
2. "빌드 → Realtime Database → 데이터베이스 만들기". 보안 규칙은 아래처럼 두세요. 로그인 없이 동작하면서
   낯선 사람이 데이터베이스를 통째로 읽거나 지우는 것은 막아줍니다.
   ```json
   {
     "rules": {
       "rooms": {
         "$room": {
           "players": {
             ".read": true,
             "$player": {
               ".write": true,
               ".validate": "newData.hasChildren(['name','x','z'])"
             }
           }
         }
       }
     }
   }
   ```
   수업이 끝나면 `.read` / `.write` 를 `false` 로 바꿔 잠가두는 걸 권장합니다.
3. 프로젝트 설정(톱니바퀴) → "내 앱" → "웹 앱 추가"(</>)에서 나오는 `firebaseConfig` 값을
   `src/multiplayer.js` 의 `FIREBASE_CONFIG` 에 넣고 `npm run build` 로 `index.html` 을 다시 만듭니다.

## 방 나누기

링크 끝에 `?room=1반` 처럼 붙이면 방이 분리됩니다 (기본값 `daechi-classroom`). 방 이름의
`. $ # [ ] /` 는 자동으로 `-` 로 바뀝니다.

## 저장소 공개와 보안

GitHub Pages 를 무료로 쓰려면 저장소가 공개여야 하고, Firebase 웹 API 키는 어차피 게임에 접속한 누구나
브라우저에서 볼 수 있는 공개 값입니다. 진짜 방어선은 위의 Realtime Database 보안 규칙입니다.
