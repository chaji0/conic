# 베리의 대치동마실 — PRD (Product Requirements Document)

> 작성일: 2026-09-13
> 작성 목적: claude.ai에서 초안 작성 → 클로드코드로 이관하여 구현

---

## 1. 개요

**게임명**: 베리의 대치동마실
**주인공**: 고양이 캐릭터 '베리'

대치동·도곡동 일대를 실제 지형에 기반해 탐험할 수 있는 3D 게임.
구글맵 스트릿뷰 이미지를 수집하여 3D 게임 월드를 생성하고,
플레이어는 고양이 '베리'가 되어 실제 동네와 유사한 공간을 자유롭게 돌아다니며 탐험한다.

- **개발 단계 구성**: 1단계 — 탐험형 맵 완성 → 2단계 — 미션/목표 시스템 추가
- **용도(가정)**: 개인 취미/학습 프로젝트 *(공개 배포로 바뀌면 구글맵 이용약관 재검토 필요 — 8번 항목 참고)*
- **플랫폼(가정)**: 웹 브라우저에서 실행 가능한 3D 게임 *(추후 변경 가능)*

---

## 2. 대상 범위 (지리적 스코프)

| 구분 | 내용 |
|---|---|
| 지역 | 대치동, 도곡동 (전체 아님, 특정 블록 한정) |
| 중심지 | **단대부고** (단국대학교사범대학부속고등학교, 서울 강남구 대치동 1013번지, 대치역 인근) |
| 포함 요소 | 주요 역(지하철역), 상점가, 학교, 아파트 단지, 조경/공원 |
| 규모 | 몇 개 블록 단위 (단대부고를 기준점으로 확장) |

**→ 다음 단계에서 확정할 것**: 단대부고를 중심으로 실제 스캔할 반경/블록 경계를
좌표(위도/경도) 범위로 지정 — 예: 단대부고 ~ 대치역 ~ 인근 아파트 단지까지

---

## 3. 제작 파이프라인

```
[1] 대상 블록 좌표 확정
        ↓
[2] 구글맵 스트릿뷰 API로 이미지 수집 (건물 외관, 거리, 랜드마크)
        ↓
[3] Meshy AI 웹사이트에서 수동으로 이미지 → 3D 모델 변환 (무료 크레딧)
        ↓
[4] 게임 엔진에 3D 에셋 배치 및 맵 구성
        ↓
[5] 게임플레이 로직 추가 (이동, 상호작용, 탐험 요소)
        ↓
[6] 완성된 게임은 정적 에셋만으로 구동 (런타임에 구글맵/힉스필드 API 호출 불필요)
```

**중요 원칙**: 구글맵·힉스필드는 **제작 단계에서만** 사용하는 도구이며, 완성된 게임 자체는
이 두 서비스에 실시간으로 의존하지 않는다 (오프라인 실행 가능).

---

## 4. 핵심 기능

### 1단계 — 탐험형 맵 (우선 구현)
- [ ] 고양이 캐릭터 '베리'가 대치동/도곡동 지형을 자유롭게 걸어다니며 탐험
- [ ] 주요 랜드마크(역, 학교, 아파트, 상점) 근처에서 상호작용 또는 정보 표시
- [ ] 조경/공원 등 랜드마크 시각적 재현

### 2단계 — 미션 시스템 (1단계 완성 후 추가)
- [ ] 구체적인 미션/목표 구조는 1단계 완성 후 별도 논의 예정

---

## 5. 기술 스택 (초안 — 확정 필요)

| 영역 | 후보 |
|---|---|
| 맵/스트릿뷰 데이터 수집 | Google Maps Platform API (Street View Static API) |
| 이미지 → 3D 에셋 변환 | **Meshy AI 웹사이트 수동 이용** (무료 플랜, 월 100크레딧) — API/MCP는 유료(Pro) 전용이라 제외, 이미지 업로드 → 모델 다운로드 → 클로드코드 프로젝트에 직접 복사하는 방식 |
| 게임 엔진/런타임 | 미정 — 웹 기반이면 Three.js / 웹 게임 프레임워크 등 검토 필요 |
| 구현 환경 | 클로드코드 (이 PRD를 이관하여 구현) |

> ⚠️ 참고: 구글 플로우(Google Flow)는 영상/이미지 생성 도구(Veo/Imagen 기반)로,
> 게임에 쓸 수 있는 3D 메쉬를 생성하지 않아 이 파이프라인에는 적합하지 않음.

---

## 6. 데이터 수집 시 고려사항

- 스트릿뷰 이미지 수집 범위(좌표 리스트)를 미리 목록화
- 이미지 수집 → 힉스필드 변환 과정에서 결과물 품질 편차 가능 → 샘플 테스트 먼저 진행 권장
- 실제 상점/학교 등은 실명 그대로 쓸지, 가상 이름으로 각색할지 결정 필요

---

## 7. 마일스톤 (초안)

1. **좌표/범위 확정** — 대상 블록 좌표 리스트 작성
2. **스트릿뷰 샘플 수집 + 힉스필드 변환 테스트** — 파이프라인 검증
3. **게임 엔진 선택 및 기본 맵 이식**
4. **게임플레이 로직 구현** (클로드코드에서 진행)
5. **테스트 및 보완**

---

## 8. 리스크 / 확인 필요 사항

- **구글맵 이용약관**: 스트릿뷰 이미지를 다운로드하여 영구 저장·재가공(3D 변환) 후 배포하는 것이
  Google의 이용약관에 부합하는지 확인 필요. 개인/비공개 학습용이면 리스크가 낮지만,
  외부 공개 배포 시 반드시 재검토.
- **Meshy 무료 크레딧 한도**: 월 100크레딧으로 대상 블록 분량(건물·거리 다수)을
  다 변환할 수 있는지 실제 테스트 필요. 부족하면 여러 달에 나눠 진행하거나 일부만 우선 변환.
- **실명 사용 여부**: 실제 학교/상점 이름 사용 시 초상권/상표 관련 이슈 가능성 — 별도 검토.
